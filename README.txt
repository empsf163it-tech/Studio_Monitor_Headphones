SonoVis — Studio Monitor Headphones Website
===========================================

Files:
- index.html       Homepage
- headphones.html  Product catalog with search and use-case filter
- product.html     Reusable product detail page (opens with ?id=m20x, etc.)
- compare.html     Interactive two-product comparison
- guides.html      Buying guide
- about.html       About page
- styles.css       Shared responsive design
- script.js        Mobile menu, filtering, product details, comparison

How to run:
1. Extract the ZIP file.
2. Open index.html in a browser.
3. For best results, use a simple local server or VS Code Live Server.
4. Internet access is needed for Google Fonts and the remote demo product photos.

Brand:
SonoVis — a modern studio monitor headphones guide concept.

Important:
Product listings are examples. Verify specifications, current prices, exact model variants, and availability before publishing. Images are remote demo images and may not show the exact named model. Replace them with properly licensed, accurate product images before launch.
